# Grimhold

Grimhold est un jeu de donjon en mode texte qui tourne dans le terminal, écrit en Go avec uniquement la bibliothèque standard. Le joueur tape des commandes dans une boucle (REPL) pour voyager entre des régions maudites décrites dans `world.json`. Il explore, tombe sur des monstres et les combat aux dés, puis note ses victimes dans un bestiaire. Les données des monstres viennent en direct de l'API [Open5e](https://open5e.com) (D&D 5e SRD, gratuite, sans clé), avec un cache en mémoire. La partie peut être sauvegardée dans `save.json`, puis reprise plus tard.
